# EBA Rural — landing lista para Netlify Drop

1. Entrá a https://app.netlify.com/drop
2. Arrastrá esta carpeta (o `../landing-eba-rural.zip`). `index.html` está en la raíz.

Contenido: `index.html` (datos embebidos, sin dependencias salvo la fuente Inter de Google Fonts), `img/`, favicons.

Privacidad: el HTML no contiene coordenadas, teléfonos del publicante, URLs ni nombres de los avisos. La ficha solicita esos datos por WhatsApp (registro + NDA).
